BDFR LogonUI wallpaper folder

Place packaged/default wallpaper images in this folder.

The Lock Screen gallery only reads manual wallpaper choices from:
1. this wallpaper folder beside BDFR.LogonUI.Demo.exe
2. %USERPROFILE%\Pictures\LockScreen

There is intentionally no unrestricted file browser in the lock experience.

Season Carousel is separate and reads Anahita's seasonal photo gallery:
%LOCALAPPDATA%\Programs\Anahita\picture\theme\season backgrounds

Anahita naming:
Spring_1.jpg, Spring_2.jpg, ...
Summer_1.jpg, ...
Autumn_1.jpg, ...
Winter_1.jpg, ...

PNG/JPEG/BMP/WEBP are appropriate manual wallpapers.
